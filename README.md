# dsh-wallpaper-cnr

给 DeepSeek Harness Web UI 使用的开源壁纸插件。上传自己的图片，设为启动后的工作区、空白会话 Hero、对话页和侧栏背景。

> 非官方插件，与 DeepSeek / DeepSeek Harness 官方无隶属关系。  
> 许可证：MIT。第三方内容、截图和引用说明见 [提示.md](提示.md)。

![界面截图（用户提供的实际效果图）](docs/show.PNG)

## 功能

- 上传 JPG、PNG、WebP 等浏览器可解码的图片。
- 在浏览器内自动缩放、压缩，再保存到本地。
- 支持填满、适应、平铺三种显示方式。
- 可调节背景可见度、模糊、遮罩强度。
- **无遮罩**模式：去掉图片上的色罩，让界面以近乎透明的方式叠在图片上。
- 可调字体颜色：跟随主题、白色、深色，或任选自定义颜色。
- **配置方案**：本地最多保存 3 套独立配置，可新建、切换、重命名和删除；每套配置自动保存。
- 配置可导出为单个 JSON 文件，在另一台机器或另一个浏览器导入即可恢复背景和全部界面配色。
- 快捷配色：**深色玻璃 / 浅色玻璃 / 跟随主题**，一键匹配文字、面板和高亮框。
- 可分别调节**对话框 / 卡片颜色**与不透明度，覆盖对话框、设置卡片、输入框、消息气泡和侧栏顶部输入区。
- 可分别调节**高亮框颜色**与不透明度，修复白字下代码块、行内代码发白的问题。
- 可分别调节**按钮颜色**与不透明度，覆盖主操作、发送、工具栏、左侧“新建会话”区域和输入框左侧圆形添加按钮。
- 可分别调节**文件标题背景**与不透明度，覆盖文件变更卡片、文件预览和代码块标题。
- 可分别调节**选中颜色**与不透明度；选中文字颜色支持自动对比或自定义。
- 可独立调节**弹窗遮罩**的深浅。
- 可随时关闭背景；图片不会被删除。
- 背景图与偏好只保存在当前浏览器，不会上传到服务器。

插件是纯 Client 实现：Host 入口为空，背景渲染、图片处理和存储都在浏览器端完成。

## 安装

仓库必须为公开仓库。推荐在 DeepSeek Harness Web UI 中安装：

1. 打开 **Plugins**。
2. 点击 **Add plugin → Install a third-party plugin**。
3. 粘贴 Git 地址：

   ```text
   github:CNRuiRen/dsh-custom-plugin
   ```

4. 安装并启用 bundle。

也可以在终端执行：

```sh
dsh plugin --profile <profile> add github:CNRuiRen/dsh-custom-plugin
```

把 `<profile>` 换成要修改的 DSH profile，例如 `desktop`。

包名：`dsh-wallpaper-cnr`。当前版本：`0.0.6`。

## 使用

打开 **设置 → 背景图片**：

0. **配置方案**区可新建、切换、重命名、删除、导入和导出配置；最多保存 3 个本地方案。
1. 上传图片。
2. 选择填充方式。
3. 选择 **遮罩效果**：
   - **柔和**：保留一层底色，文字更稳。
   - **无遮罩**：图片保持清晰，界面近乎透明。
4. 按需调整 **快捷配色**、**字体颜色**、**对话框 / 卡片颜色**、**高亮框颜色**、**按钮颜色**、**文件标题背景**、**选中颜色**、**弹窗遮罩**、背景可见度、模糊和遮罩强度。
5. 关闭设置，背景会应用到工作区和启动界面。

### 字体与界面配色

- **字体颜色**通过 DSH 的主题文字 Token 生效，会影响主标题、正文、侧栏文字、辅助说明和图标颜色。
- 选择白色或浅色字体时，插件会自动把尚为「跟随主题」的对话框、高亮框和文件标题切到深色半透明方案，避免白字落在白色块里看不清。
- **对话框 / 卡片颜色**控制对话框、设置卡片、输入框、消息气泡、侧栏顶部输入区和代码输入区。
- **高亮框颜色**控制行内代码、代码块、标签和悬停高亮。
- **按钮颜色**控制主操作、发送、工具栏、左侧新建会话区域和输入框左侧圆形添加按钮。
- **文件标题背景**控制文件变更卡片、文件预览和代码块标题栏。
- **选中颜色**控制左侧导航选中项、选中的标签和文字光标选区；**选中文字颜色**可自动按背景选择黑/白，也可手动指定。
- **弹窗遮罩**独立于壁纸遮罩，只控制弹出窗口背后的暗色遮罩。

### 配置方案与导出

- 本地最多 3 个方案，方案之间互不影响。
- **导出**生成一个 JSON 文件，内含当前方案的全部设置和背景图。
- **导入**会新建一个方案并切换过去；达到上限时先删除一个。
- 导出的文件可能包含个人图片，请按个人数据保管。

### 图片保存位置

图片和配置保存在浏览器 `localStorage` 中，并按浏览器来源（协议 + 主机 + 端口）隔离。DSH 重启后端口变化、换浏览器或清除站点数据时，本地数据不会自动共享；请先导出配置，再在新环境导入。

## 兼容性

- 在 DeepSeek Harness `0.2.1-rc.5` Web UI 上测试。
- 仅支持 Web UI；不适用于没有 Web 前端的 profile。
- 需要目标版本提供 `settings.section` 插槽与 Client 插件加载能力。

## 开发

```sh
git clone git@github.com:CNRuiRen/dsh-custom-plugin.git
cd dsh-custom-plugin
```

把本地目录安装到 DSH profile 后即可调试：

```sh
dsh plugin --profile <profile> add /absolute/path/to/dsh-custom-plugin
```

开发分支：`dev`。
